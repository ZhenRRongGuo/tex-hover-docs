# Changelog

## [0.1.0]

### Added

- Hover documentation for custom LaTeX classes and Beamer themes.
- Class and theme descriptions with a summary of documented options.
- Option descriptions, defaults, documented values, and value descriptions.
- Documentation stored in comment blocks in `.cls` and `.sty` files, with trailing commas supported.
- Workspace lookup with a `kpsewhich` fallback for installed TeX files.
- Configurable `texHoverDocs.kpsewhichPath` executable path.
- Support for unsaved metadata edits in open definition files.
- English and Simplified Chinese documentation.
